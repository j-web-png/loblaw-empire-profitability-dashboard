# Loblaw vs Empire Profitability Dashboard

## Project Overview

This project compares Loblaw Companies Limited and
Empire Company Limited using gross profit margin and
adjusted EBITDA margin.

## Research Question

How do Loblaw and Empire compare in profitability,
and what factors explain their differences?

## Dashboard Features

- Gross profit margin comparison
- Adjusted EBITDA margin comparison
- Business mix analysis
- Strategic recommendations
- Financial methodology and source references

## Technology

- HTML
- CSS
- JavaScript
- Chart.js
- GitHub Pages

## Data Sources

Loblaw:
https://www.loblaw.ca/en/investors-reports/

Empire:
https://www.empireco.ca/financial-highlights

## Methodology

Gross Profit Margin =
(Gross Profit / Revenue) * 100

Adjusted EBITDA Margin =
(Adjusted EBITDA / Revenue) * 100

## Data Limitations

Some preliminary figures have different reporting
periods and segment definitions.

These figures must be checked against official
financial statements before final submission.

Missing figures are not assumed to be zero.

## Deployment

The dashboard is designed for GitHub Pages.

1. Upload the project files to a public repository.
2. Open repository Settings.
3. Select Pages.
4. Select Deploy from a branch.
5. Choose main and root.
6. Save and open the published website.
